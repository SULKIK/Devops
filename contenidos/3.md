CI/CD son siglas que hacen referencia a dos prácticas esenciales en el desarrollo
moderno de software:
CI: Integración Continua (Continuous Integration)
¿ Qué es ?
Es la práctica de integrar los cambios de código de todos los desarrolladores en un
repositorio compartido de forma frecuente.
Objetivo:
Detectar errores de manera temprana y asegurarse de que el código nuevo funcione con
el existente.
¿Cómo funciona?
Los desarrolladores envían su código a un repositorio central. Cada vez que hay un
cambio, se ejecutan tests automáticos y otras verificaciones Si algo falla, los
desarrolladores reciben notificaciones inmediatas para arreglarlo.
CD: Entrega Continua / Despliegue Continuo (Continuous Delivery / Continuous
Deployment)
Aquí hay que diferenciar dos términos similares:
1.Entrega Continua (Continuous Delivery):
1. El código que pasó la CI se prepara automáticamente para ser lanzado a
producción, pero la publicación en producción se hace manualmente.
2. Garantiza que cualquier versión pueda ser desplegada con un solo clic.
2.Despliegue Continuo (Continuous Deployment):
1. Va un paso más allá: cada cambio que pasa la CI y todas las pruebas se
despliega automáticamente a producción sin intervención humana.
Objetivo:
Automatizar la entrega de software para que sea rápida, confiable y sin errores humanos.
En pocas palabras:
CI = probar código constantemente,
CD = entregar/desplegar código automáticamente.
CI es la base sobre la que CD se construye.
